# Штурман поездок

Сайт-планировщик поездок. Человек отвечает на 7 вопросов (кто едет и откуда, паспорт, куда тянет, даты, бюджет, перелёт и жильё), а Claude собирает поездку: маршрут по городам, перелёты, жильё, места, план по дням, бюджет, визы и чек-лист.

## Этапы

- [x] **Этап 1 — основа.** Next.js, перенос опроса и дизайна, маршрут строит Claude API на сервере (ключ только на сервере, у посетителя ничего не нужно).
- [ ] **Этап 2 — реальные данные.** Рейсы и отели (Travelpayouts / Duffel), места и фото (Google Places), выбор лучшего варианта.
- [ ] **Этап 3 — сохранение и шеринг.** База (Supabase), ссылка на поездку, «Мои поездки».
- [ ] **Этап 4 — полировка.** Иврит/английский, PWA, кэш цен, общий лимит запросов.
- [ ] **Этап 5 — запуск.** Домен, аналитика, условия и конфиденциальность.

## Запуск локально

```bash
cp .env.example .env.local   # впишите ANTHROPIC_API_KEY
npm install
npm run dev                  # http://localhost:3000
```

## Как устроено

| Где | Что |
|---|---|
| `src/app/page.tsx` | Оболочка страницы, запускает интерфейс |
| `src/client/shturman.js` | Интерфейс: согласие, главная, опрос, 7 страниц поездки (перенесён из прототипа) |
| `src/app/globals.css` | Дизайн: палитра, шрифты, компоненты |
| `src/app/api/plan/route.ts` | `POST /api/plan` — строит маршрут через Claude API и стримит прогресс (NDJSON) |
| `src/lib/prompt.ts` | Проверка ответов опроса и сборка промпта на сервере |
| `src/lib/rate-limit.ts` | Лимит поездок в час с одного IP (`PLANS_PER_HOUR`) |

Модель: `claude-opus-5-5`, effort `medium`, серверный fallback при отказе (`fallbacks: "default"`).

## Деплой на Vercel

1. Импортируйте репозиторий в Vercel.
2. В Settings → Environment Variables добавьте `ANTHROPIC_API_KEY` (и при желании `PLANS_PER_HOUR`).
3. Deploy.
